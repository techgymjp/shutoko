# 首都高グランプリ

首都高速をフォーミュラマシンで駆け抜ける、ブラウザで遊べる 3D レースゲームです（three.js）。
最初のコースは **高井戸IC → 4号新宿線 → 三宅坂JCT → C1都心環状線（内回り）霞が関 → 谷町JCT → 3号渋谷線 → 用賀**（約26km）。
12台のマシンがドライバー目線で全開バトルします。

## 遊び方

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| アクセル | ↑ / W / Space / Z | ACCEL ボタン |
| ブレーキ | ↓ / S / X | BRAKE ボタン |
| ハンドル | ← → / A D | ◀ ▶ ボタン |
| 一時停止 | P / Esc | ❚❚ ボタン |
| ERS（末脚） | Shift / E / C | ERS ボタン |
| 消音 | M | 🔊 ボタン |

- タイトル画面で**ドライバー名**を付けられる（順位表と結果に出る）。マシンの脚質・戦績・ベストタイムは名前ごとに保存され、別の名前にすると新しいマシンになる
- **最後尾（12番グリッド）からスタート**。5つの赤いスタートシグナルが消えたらスタート
- **ERS（末脚）**: `Shift` / `E`（スマホは ERS ボタン）を押している間、最高速と加速が上がる。風よけ（スリップストリーム）とブレーキで溜まる
- **先頭の重圧**: トップに立って2.5秒たつと、先頭は風よけがないので12秒間ペースダウンして後続に抜かれる（ゴール前500mからは起きない）。
  自分がトップの間は後続も本気で追い上げてくる。**2〜3番手で溜めて、ゴール間際で差す**のが基本の作戦
- **追い上げブースト**: 順位が下のときほど最高速と加速が少し上がる（最下位で +8%）
- **スリップストリーム**: 前の車の真後ろにつくと速度が伸び、ERS も溜まる
- **抜きつ抜かれつ**: ライバルはカーブでも減速しない。自分より後ろの車は一律に最高速360km/h以上。さらに後ろ300m以内の車は自分の速度を目安に追いかけてくる（トップの時は自分より6%以上速く）
- **後続の奥の手（オーバーテイクモード）**: トップに立つと、すぐ後ろの車が ERS を全開にして（テールが青く光る）7秒間ぐっと速くなり、狭い隙間にもねじ込んで抜きに来る。横から当たると自分のほうが押し出される。次の奥の手までは12秒あく
- 2車線の真ん中を走って道をふさいでも、ライバルは隙間に飛び込み、車体をこすって火花を散らしながら抜いていく（当たり判定の幅は1.6m）

### 脚質（ダービージョッキー方式）

[ダービージョッキー](https://github.com/techgymjp/keiba) の脚質の考え方をフォーミュラマシンのレースに置き換えています。
マシンの脚質は最初にランダムで決まり、**隠れていて**、走りながら見抜きます（テスト用に `index.html?debug&style=sashi` のように開くと脚質を指定できます）。
マシンには「走っていて心地よい順位」があり、そこで走ると ERS がよく溜まり、前に出すぎるとマシンが熱を持って回生できず ERS が減っていきます。

| 脚質 | 心地よい位置 | 特徴 | 先頭の重圧 |
| --- | --- | --- | --- |
| 逃げ | 先頭 | 最高速・加速・コーナーが強い。ERS は短い | −5% |
| 先行 | 2〜4番手 | 前の集団で風よけを使い、残り1kmで抜け出す | −10% |
| 差し | 5〜8番手 | 中団で ERS を溜めてゴール前で差す | −12% |
| 追込 | 9〜12番手 | 最高速は控えめだが ERS が大容量。最後の直線でまくる | −14% |

- 見抜く手がかりは、レース中のチーム無線（「前に出すぎだ! マシンが熱を持って…」など）と、レース後のチーフエンジニアのコメント。1位になると脚質が判明する（ドライバー名ごとにブラウザに保存）
- レース後のコメント例: 「ゴールしても ERS がたっぷり残っていた。仕掛けが遅かった」「ゴールまで2.3kmで ERS を使い切った。仕掛けが早すぎた」
- 三宅坂JCT・谷町JCT の急カーブは速すぎると外へ滑って壁に当たる。壁に当たると速度が15〜40%落ち、こすり続けると大きく減速するので、ブレーキで減速して曲がる
- 順位表と「後続」の秒差は、各車がコースの同じ地点を通った時刻の差（実際のレースと同じ測り方）
- **ぶつかっても壊れない**。火花・カーボンの破片・タイヤスモーク・画面の揺れとフラッシュ・衝撃音・スロー演出のあと、失速やスピンをしてそのまま走り続ける
- 時間帯は「昼」「夕暮れ」「夜」から選べる（夜は自車のヘッドライト、ライバル車のテールランプ、窓明かり・照明灯・航空障害灯）
- ベストタイムはブラウザに保存
- 結果画面の「シェアする」でスマホは端末の共有メニュー、パソコンは X の投稿画面を開く（「結果をコピー」で文章をコピー）。共有文には紹介記事の URL（https://techgym.jp/column/claude-code-game-shutoko/ 。`js/main.js` の `SHARE_URL`）が付く

## 加速感の作り方（酷道168 を参考）

- 加速は「速度が上がるほど弱くなる」カーブ（0→100km/h 約2.5秒、最高 340km/h）
- 速度が上がるほど視野角が広がり（ズームアウト）、画面の周りに集中線、細かい車体の振動
- 照明柱・橋脚・遮音壁の支柱・キロポストが一定間隔で流れ、速さが体で分かる
- エンジン音は回転数とギア（8速）で変化し、シフトアップの音、風切り音、近くのライバル車のエンジン音（左右の定位つき）

## 再現している景色

道路の線は **OpenStreetMap** の首都高（4号・C1・3号と三宅坂JCT・谷町JCT のランプ）を一方通行どおりにつないだ実際の経路で、橋・トンネルの区間と高さ（layer）から高架・地下の高さを決めています。
沿道のビルは **国土交通省 PLATEAU** の3D都市モデル（東京都23区）の実際の輪郭と高さ（コース沿い約4.8万棟）で、道路にかかる建物だけ除いています。
道路は片側2車線（車線幅3.5m）、壁高欄・遮音壁・中央分離帯の照明柱・対向車線、首都高の緑の案内標識（出口・JCT の 1km / 500m 予告）を置いています。

## ルート（タイトル画面で選ぶ。準備中のものは「準備中」と表示）

1. **高井戸 → 霞が関 → 用賀**（遊べる）… 4号新宿線・C1内回り・3号渋谷線
2. **C1 都心環状線 一周**（遊べる・内回り13.8km）… 芝公園スタート → 浜崎橋JCT → 汐留 → 銀座の掘割 → 宝町 → 江戸橋JCT → 神田橋 → 竹橋JCT → 北の丸・代官町（皇居のお濠沿い）→ 三宅坂JCT → 霞が関のトンネル → 谷町JCT → 一ノ橋JCT → 芝公園ゴール。急カーブとトンネルが続くテクニカルコース
3. **レインボーブリッジ ＆ 湾岸線**（遊べる・9.6km）… 芝浦JCT → 海の上の高さ約50mのレインボーブリッジ（白い主塔の間を抜ける）→ 台場 → 有明JCT → 湾岸線 西行き → 海の下の東京港トンネル → 大井JCT → 東海JCT。夜景がおすすめ
4. **レインボーブリッジ 都心行き**（遊べる・10.2km）… 辰巳 → 有明JCT → 台場 → レインボーブリッジ（壁が低く海と街が見える）→ 芝浦 → 浜崎橋JCT → C1 外回り（東京タワーの横）→ 一ノ橋JCT → 飯倉。夕暮れは正面に夕日と富士山
5. **山手トンネル 地下バトル**（遊べる・20.7km）… C2 中央環状線 大井JCT → 大橋JCT → 西新宿JCT → 中野長者橋 → 西池袋 → 熊野町JCT。約18km がトンネル（大橋JCT の二重ループはランプなので走らない）
6. **向島線 スカイツリー**（遊べる・8.4km）… 江戸橋JCT → 箱崎JCT → 両国（国技館）→ 駒形 → 隅田川沿い → 向島。全区間高架、正面にスカイツリー
7. **1号羽田線 運河ストレート**（遊べる・12.7km）… 羽田 → 空港西 → 平和島 → 鈴ヶ森 → 芝浦の運河沿い → 浜崎橋JCT。羽田へ降りる飛行機が道路の上を横切る
8. **5号池袋線 サンシャイン**（遊べる・15.8km）… 竹橋JCT → 西神田 → 飯田橋 → 江戸川橋 → 護国寺 → 東池袋（サンシャイン60）→ 北池袋 → 熊野町JCT → 板橋JCT → 中台 → 高島平。川の上をくねくね北上してから長い直線
9. **湾岸線 東行き 海底トンネル**（遊べる・11.8km）… 大井JCT → 海の下の東京港トンネル → 臨海副都心 → 有明JCT → 東雲JCT → 辰巳JCT → 新木場 → 葛西JCT。ビッグサイトと葛西臨海公園の大観覧車
10. **2号目黒線 タワー下り**（遊べる・8.2km）… 霞が関 → 谷町JCT → 飯倉（東京タワー）→ 一ノ橋JCT → 天現寺 → 目黒 → 戸越。カーブの多い短距離スプリント

PLATEAU のデータがある東京23区内でそろえています。新しいルートは、下の「コースデータの作り方」で OSM の経路と PLATEAU の建物からデータを作り、`js/courses.js` に区間テロップ・出口・ランドマークを足せば遊べます。

## 実行方法

ビルドは不要です。静的ファイルとして配信してブラウザで `index.html` を開きます（ES Modules を使うため `file://` では動きません）。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

## コースデータの作り方

`js/course-data.js`（道路の線・高さ・トンネル区間・建物）は次の手順で作ります。

1. OpenStreetMap API から首都高の路線リレーション（4号 4256522・C1 4256008・3号 4256376）を `/api/0.6/relation/<id>/full` で、三宅坂JCT・谷町JCT 付近を `/api/0.6/map?bbox=` で取得
2. `python3 tools/osm_route.py` … 一方通行どおりに 高井戸 → 霞が関 → 用賀 の経路を求めて `path.json` に出力
   （C1 一周は `python3 tools/osm_loop.py rc1.osm "Inner directions" 35.65385 139.74786 > path_c1.json`、
   ほかのルートは `python3 tools/osm_path.py --osm <路線のデータ…> --via 緯度,経度 --via … > path_xx.json` で通過地点をたどる。
   路線リレーション: 11号台場線 4257564・湾岸線 4256202・中央環状線 4256077・6号向島線 4256960・1号羽田線 4256244・5号池袋線 4256611・2号目黒線 4256339）
3. PLATEAU 東京都23区 CityGML（2020年度）から、コース沿いの3次メッシュの建物（`udx/bldg`）の輪郭（lod0RoofEdge）・高さ（measuredHeight）・名前を取り出す
4. `python3 tools/build_course.py path.json <建物のディレクトリ> > js/course-data.js`
   （C1 一周は `python3 tools/build_course.py path_c1.json <建物のディレクトリ> C1_DATA --loop > js/course-c1-data.js`。ゴールのあともスタートの先へ道とビルが続く）

データの出典: © OpenStreetMap contributors（ODbL）／ 国土交通省 Project PLATEAU（PLATEAU サイトポリシー、CC BY 4.0 互換）。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `js/course-*.js` | 各コースの道路の線・高さ・トンネル区間・建物（自動生成） |
| `js/courses.js` | コース定義（区間・出口・緑地・ランドマーク）と提案ルート。テックジム（アドバルーン）・東京タワー・国会議事堂・スカイツリー・富士山は全コース共通の目印 |
| `js/route.js` | 道路の線を 2m 間隔にし、位置・向き・曲率・高さを引けるようにする |
| `tools/` | コースデータを作るスクリプト（OSM の経路探索・PLATEAU の建物の取り込み） |
| `js/world.js` | 高架・壁高欄・遮音壁・トンネル・照明・標識・PLATEAU のビル群・空（チャンク単位で生成） |
| `js/models.js` | レーシングマシン、ランドマーク、テクスチャ（路面・窓・標識） |
| `js/cockpit.js` | ドライバー目線のコクピット（ノーズ・前輪・ヘイロー・ステアリングの表示とシフトランプ） |
| `js/main.js` | レース進行、操作、AI、接触、カメラ、HUD |
| `js/effects.js` | 火花・破片・タイヤスモーク |
| `js/traffic.js` | 対向車線の一般車 |
| `js/audio.js` | 効果音（すべて WebAudio で合成） |

テスト用に `index.html?debug` で開くと、コンソールから `dbg.warp(距離m)` で好きな地点へ移動できます。
