# 首都高F1グランプリ

首都高速を F1 マシンで駆け抜ける、ブラウザで遊べる 3D レースゲームです（three.js）。
最初のコースは **高井戸IC → 4号新宿線 → 三宅坂JCT → C1都心環状線（内回り）霞が関 → 谷町JCT → 3号渋谷線 → 用賀**（約26km）。
12台のマシンがドライバー目線で全開バトルします。

## 遊び方

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| アクセル | ↑ / W / Space / Z | ACCEL ボタン |
| ブレーキ | ↓ / S / X | BRAKE ボタン |
| ハンドル | ← → / A D | ◀ ▶ ボタン |
| 一時停止 | P / Esc | ❚❚ ボタン |
| ERS（末脚） | Shift / E / C | ERS ボタン |
| 消音 | M | 🔊 ボタン |

- タイトル画面で**ドライバー名**を付けられる（順位表と結果に出る）
- **最後尾（12番グリッド）からスタート**。F1 と同じ5つの赤いシグナルが消えたらスタート
- **ERS（末脚）**: `Shift` / `E`（スマホは ERS ボタン）を押している間、最高速と加速が上がる。風よけ（スリップストリーム）とブレーキで溜まる
- **先頭の重圧**: トップに立って2.5秒たつと、先頭は風よけがないので12秒間ペースダウンして後続に抜かれる（ゴール前500mからは起きない）。
  自分がトップの間は後続も本気で追い上げてくる。**2〜3番手で溜めて、ゴール間際で差す**のが基本の作戦
- **追い上げブースト**: 順位が下のときほど最高速と加速が少し上がる（最下位で +8%）
- **スリップストリーム**: 前の車の真後ろにつくと速度が伸び、ERS も溜まる
- 2車線の真ん中を走って道をふさいでも、ライバルは隙間に飛び込み、車体をこすって火花を散らしながら抜いていく（当たり判定の幅は1.6m）

### 脚質（ダービージョッキー方式）

[ダービージョッキー](https://github.com/techgymjp/keiba) の脚質の考え方を F1 に置き換えています。
マシンの脚質は**隠れていて**、走りながら見抜きます（`index.html?debug` で開いた時だけ、タイトルで脚質を選べます）。
マシンには「走っていて心地よい順位」があり、そこで走ると ERS がよく溜まり、前に出すぎるとマシンが熱を持って回生できず ERS が減っていきます。

| 脚質 | 心地よい位置 | 特徴 | 先頭の重圧 |
| --- | --- | --- | --- |
| 逃げ | 先頭 | 最高速・加速・コーナーが強い。ERS は短い | −5% |
| 先行 | 2〜4番手 | 前の集団で風よけを使い、残り1kmで抜け出す | −10% |
| 差し | 5〜8番手 | 中団で ERS を溜めてゴール前で差す | −12% |
| 追込 | 9〜12番手 | 最高速は控えめだが ERS が大容量。最後の直線でまくる | −14% |

- 見抜く手がかりは、レース中のチーム無線（「前に出すぎだ! マシンが熱を持って…」など）と、レース後のチーフエンジニアのコメント。1位になると脚質が判明する（ブラウザに保存。「新しいマシンに乗り換える」でやり直し）
- レース後のコメント例: 「ゴールしても ERS がたっぷり残っていた。仕掛けが遅かった」「ゴールまで2.3kmで ERS を使い切った。仕掛けが早すぎた」
- 三宅坂JCT・谷町JCT の急カーブは速すぎると外へ滑って壁に当たる。ブレーキで減速して曲がる
- **ぶつかっても壊れない**。火花・カーボンの破片・タイヤスモーク・画面の揺れとフラッシュ・衝撃音・スロー演出のあと、失速やスピンをしてそのまま走り続ける
- 時間帯は「昼」「夕暮れ」「夜」から選べる（夜は自車のヘッドライト、ライバル車のテールランプ、窓明かり・照明灯・航空障害灯）
- ベストタイムはブラウザに保存

## 加速感の作り方（酷道168 を参考）

- 加速は「速度が上がるほど弱くなる」カーブ（0→100km/h 約2.5秒、最高 340km/h）
- 速度が上がるほど視野角が広がり（ズームアウト）、画面の周りに集中線、細かい車体の振動
- 照明柱・橋脚・遮音壁の支柱・キロポストが一定間隔で流れ、速さが体で分かる
- エンジン音は回転数とギア（8速）で変化し、シフトアップの音、風切り音、近くのライバル車のエンジン音（左右の定位つき）

## 再現している景色

道路の線は **OpenStreetMap** の首都高（4号・C1・3号と三宅坂JCT・谷町JCT のランプ）を一方通行どおりにつないだ実際の経路で、橋・トンネルの区間と高さ（layer）から高架・地下の高さを決めています。
沿道のビルは **国土交通省 PLATEAU** の3D都市モデル（東京都23区）の実際の輪郭と高さ（コース沿い約4.8万棟）で、道路にかかる建物だけ除いています。
道路は片側2車線（車線幅3.5m）、壁高欄・遮音壁・中央分離帯の照明柱・対向車線、首都高の緑の案内標識（出口・JCT の 1km / 500m 予告）を置いています。

## ルート案（タイトル画面に「準備中」として表示）

1. **高井戸 → 霞が関 → 用賀**（遊べる）… 4号新宿線・C1内回り・3号渋谷線
2. **C1 都心環状線 一周**（14.8km）… 江戸橋JCT、銀座の掘割区間、浜崎橋JCT、竹橋のS字。急カーブとトンネルが続くテクニカルコース
3. **レインボーブリッジ ＆ 湾岸線** … 芝浦JCT → レインボーブリッジのループ → 有明JCT → 湾岸線 → 東京港トンネル → 大井。夜景と最高速アタック
4. **山手トンネル 地下バトル**（18.2km）… C2 中央環状線 大井JCT → 大橋JCT の二重ループ → 板橋JCT。日本一長い道路トンネル
5. **向島線 スカイツリー** … 江戸橋JCT → 箱崎JCT のロータリー → 隅田川の上 → 堀切JCT。正面にスカイツリー
6. **1号羽田線 運河ストレート** … 羽田空港 → 平和島 → 勝島の運河沿い → 芝浦 → 浜崎橋JCT。頭上をかすめる飛行機と運河の真上の直線

PLATEAU のデータがある東京23区内でそろえています。新しいルートは、下の「コースデータの作り方」で OSM の経路と PLATEAU の建物からデータを作り、`js/courses.js` に区間テロップ・出口・ランドマークを足せば遊べます。

## 実行方法

ビルドは不要です。静的ファイルとして配信してブラウザで `index.html` を開きます（ES Modules を使うため `file://` では動きません）。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

## コースデータの作り方

`js/course-data.js`（道路の線・高さ・トンネル区間・建物）は次の手順で作ります。

1. OpenStreetMap API から首都高の路線リレーション（4号 4256522・C1 4256008・3号 4256376）を `/api/0.6/relation/<id>/full` で、三宅坂JCT・谷町JCT 付近を `/api/0.6/map?bbox=` で取得
2. `python3 tools/osm_route.py` … 一方通行どおりに 高井戸 → 霞が関 → 用賀 の経路を求めて `path.json` に出力
3. PLATEAU 東京都23区 CityGML（2020年度）から、コース沿いの3次メッシュの建物（`udx/bldg`）の輪郭（lod0RoofEdge）・高さ（measuredHeight）・名前を取り出す
4. `python3 tools/build_course.py path.json <建物のディレクトリ> > js/course-data.js`

データの出典: © OpenStreetMap contributors（ODbL）／ 国土交通省 Project PLATEAU（PLATEAU サイトポリシー、CC BY 4.0 互換）。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `js/course-data.js` | 道路の線・高さ・トンネル区間・建物（自動生成） |
| `js/courses.js` | コース定義（区間・出口・緑地・ランドマーク）と提案ルート |
| `js/route.js` | 道路の線を 2m 間隔にし、位置・向き・曲率・高さを引けるようにする |
| `tools/` | コースデータを作るスクリプト（OSM の経路探索・PLATEAU の建物の取り込み） |
| `js/world.js` | 高架・壁高欄・遮音壁・トンネル・照明・標識・PLATEAU のビル群・空（チャンク単位で生成） |
| `js/models.js` | F1 マシン、ランドマーク、テクスチャ（路面・窓・標識） |
| `js/cockpit.js` | ドライバー目線のコクピット（ノーズ・前輪・ヘイロー・ステアリングの表示とシフトランプ） |
| `js/main.js` | レース進行、操作、AI、接触、カメラ、HUD |
| `js/effects.js` | 火花・破片・タイヤスモーク |
| `js/traffic.js` | 対向車線の一般車 |
| `js/audio.js` | 効果音（すべて WebAudio で合成） |

テスト用に `index.html?debug` で開くと、コンソールから `dbg.warp(距離m)` で好きな地点へ移動できます。
